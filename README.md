# Calendar

A month view planner with events stored in the browser.

## Features

- Month grid with Monday as the first day
- Previous, next and today navigation
- Click any date to select it, including dates from other months
- Add and delete events for the selected day
- Event dots on dates with something planned
- A monthly event count
- Events saved in local storage
- Two sample events on first load

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    calendar logic and storage
```

## Tech

Plain HTML, CSS and JavaScript.
